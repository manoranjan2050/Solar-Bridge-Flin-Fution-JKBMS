WHAT THIS IS
------------
A self-hosted replacement for "Solar Assistant". Runs on a Raspberry Pi. Reads a
Flin Fution inverter (Voltronic/Axpert clone) over USB-HID and dual JK BMS over
RS485, then provides:
  - A full web dashboard (Flask + Socket.IO) on port 8080
  - Home Assistant integration via MQTT auto-discovery (sensors + controls)
  - A Telegram bot (status + control + daily summary)
  - Alerts, automation rules, cost tracking, history, PWA, login, custom domain

GitHub (PUBLIC): https://github.com/manoranjan2050/Solar-Bridge-Flin-Fution-JKBMS
Branch: master. Commit/push directly to master (no PR flow needed unless asked).

================================================================================

    the ad-hoc paramiko scripts pattern used throughout (connect, sftp.put, restart).
  - deploy_secrets.py holds HOST/USER/PASS for deploy.py (git-ignored).
  - After changing solar_bridge.py / modules: restart solar-bridge.

  - Watch logs: sudo journalctl -u solar-bridge -f
  - The dashboard works WITHOUT MQTT (reads live_state.json, sends control via
    control_queue.json). MQTT is only needed for Home Assistant.
  - Verify visually with the Claude Preview MCP (run dashboard locally with a
    sample live_state.json; note: the preview proxy can't fetch /api/* so inject
    data via eval, or test endpoints directly with urllib on 127.0.0.1:8080).

KEY PROTOCOL FACTS (hard-won - don't re-derive)
================================================================================
  INVERTER (Voltronic PI30, USB-HID, 8 raw bytes/read, Voltronic table CRC):
    Set-command prefixes CONFIRMED for this unit (others return NAK):
      output priority   = POP   (00=Grid,01=Solar,02=SBU)     [NOT POPCD]
      charger priority  = PCP   (00=Grid,01=Solar,02=Sol+Grid,03=SolOnly)  [NOT PPCP]
      max charge curr   = MUCHGC + 3-digit amps  (also used for grid charge)
      float voltage     = PBFT + xx.x
      bulk voltage      = PCVV + xx.x            [NOT PBCV]
      shutdown voltage  = PSDV + xx.x
      recharge voltage  = PBDV + xx.x
    QPIRI field indices CONFIRMED:
      [14]=max_charge  [16]=output_source_priority  [17]=charger_source_priority
      (NOT [15]/[16] - was off by one)

  JK BMS (new protocol 55 AA EB 90, type-02 frame, passive broadcast):
    +6 cells(16xu16 mV) +144 MOS temp(u16) +150 pack V(u32 mV) +162/164 temp1/2(u16)
    +173 SOC(uint8)  +174 remaining mAh(u32)  +178 design mAh(u32)  +182 cycles(u32)
    +190 SOH(uint8). Two packs by byte +5: 0x00=BMS1, 0x05=BMS2.
    (SOC was previously read at wrong offset 182 -> showed 46/36 instead of ~100.)
